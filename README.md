# Catching Balls Without Catching

A simple 2D arcade survival game developed using Java and Processing for a game jam.

About the Game

The idea behind the game is simple: you're playing as a character who must avoid falling balls instead of catching them.

Survive for 60 seconds, dodge the falling objects and try to achieve the highest score possible without losing all your lives.

# Gameplay

Avoid the falling balls.

You start with 3 lives.

Each collision costs you one life.

Gain points by successfully avoiding falling objects.

Objects gradually become faster as time passes.

Survive for 60 seconds to win.

# Controls

Left Arrow / A - Move left

Right Arrow / D - Move left

Space - Start or restart the game

# Technologies Used

Java

Processing

# Project Structure

CatcherWithoutCatching.pde – Main game logic and game states.

Player.pde – Player movement and appearance.

FallingObject.pde – Falling object movement and appearance.

# How to Run

Download or clone this repository.

Open the project in Processing.

Open CatcherWithoutCatching.pde.

Press Run to start the game.

# Objective

Can you survive for 60 seconds without catching a single ball?
